✨ About

DARKHACKER MOVIEHUB is a web-based movie hub designed around a simple idea:

«Find it. Discover it. Enjoy it.»

The interface focuses on a clean cinematic experience, responsive layouts, fast navigation, and an organized way to explore movie content.

Whether you're browsing from a phone, tablet, or desktop, MovieHub is designed to keep the experience simple and enjoyable.

⚙️ Getting Started

1. Clone the repository

git clone git@github.com:mrdarkhacker091/DARKHACKER-MOVIEHUB.git

2. Enter the project

cd DARKHACKER-MOVIEHUB

3. Run locally

For a simple static preview:

python -m http.server 8000

Then open:

http://127.0.0.1:8000

🎨 Design Philosophy

MovieHub follows three simple principles:

01 — Simple

The interface should be easy to understand without unnecessary complexity.

02 — Cinematic

Dark layouts, artwork, spacing, and visual hierarchy create a movie-focused atmosphere.

03 — Fast

The interface should remain lightweight and responsive across different devices.
